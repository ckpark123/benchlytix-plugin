# Contributing

This repository is a generated mirror. The source lives in the BenchLytix repository under `packages/plugin/`, where
the tests run over it; `SOURCE_COMMIT` names the source commit each sync came from.

Pull requests here are welcome, but they are not merged here: each one is ported to the source repository, tested
there, and arrives here with the next sync. Anything changed only here is overwritten by that sync.

Wrong facts: use the "Wrong fact" issue form. Requests to have an agent tested are closed.
