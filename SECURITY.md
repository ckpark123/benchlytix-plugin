# Security

Report a vulnerability privately through GitHub's private vulnerability reporting: the "Report a vulnerability"
button on this repository's Security tab. Please do not open a public issue for a security problem.

GitHub offers private vulnerability reporting only for public repositories, so it is turned on as soon as this
repository is made public, before the plugin is announced.

This plugin holds no code that runs on your machine: two manifests, the MCP server address and (later) skill
instructions. The server it adds is `https://www.benchlytix.com/api/mcp`; what it logs is listed at
https://www.benchlytix.com/privacy#hosted-mcp
